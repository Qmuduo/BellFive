# 微信小游戏首页实施计划

目标：现有配色下实现单机优先的全新首页。
架构：保留 home.ts 的业务动作；统一首页几何；navigation.ts 保存仅在内存中的 soloDifficulty；专用 home.* 翻译避免改变其他客户端。
技术：TypeScript、微信 Canvas、Zustand、Jest、esbuild。

- [x] 更新首页测试：唯一单机入口、难度选择不启动、三种手机尺寸和滚动命中、房间更新不影响几何。先运行观察新行为失败。
- [x] navigation.ts 增加 soloDifficulty，默认 normal；home.difficulty.* 仅更新选择，home.solo.* 复用原有单机逻辑。
- [x] home.ts 重新绘制紧凑品牌栏、游戏示意和主按钮、难度选择、好友建房与输码、大厅入口、底部语言；共享几何计算高度与位置。
- [x] translations.ts 增加中英文首页文案；在线错误与取消重试适配紧凑区域。
- [x] 运行小游戏完整测试、小游戏类型检查和构建；用实际渲染器生成中英文、大屏小屏及错误状态预览。

验证结果：首页与认证流程 38 项通过；首页、认证与对战流程相关 74 项通过。小游戏全量 149 项中 148 项通过，原有对战页文案测试仍期待 27/3、26/4，而未修改的渲染器显示 27、26。小游戏类型检查及构建通过。390×844 中英文、320×568 首屏与滚动底部、网络错误恢复状态已用真实 Canvas 渲染器检查；独立代码审查无问题。
仓库级 npm run typecheck 另有未修改的 Expo app/account.tsx、app/auth.tsx、app/index.tsx 路由类型错误：生成的路由类型未包含 /auth 与 /account。该错误不影响已通过的小游戏类型检查与构建。
