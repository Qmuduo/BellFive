# BellFive 扑克牌翻牌音效与中英界面设计

## 目标

让每次出牌听起来像真实纸牌被抽出、翻面并轻放到桌上；让 BellFive 全部玩家可见界面默认使用简体中文，并允许玩家在设置中切换到英文。语言选择保存在本机，不影响房间协议或另一位玩家的语言。

## 当前情况

- `assets/audio/card-flip.wav` 是当前较短的翻牌音源；铃声和胜负音效已有独立资源。
- 牌桌的翻牌/按铃本机声音在点击时播放，对手动作在收到服务端事件后播放；本机事件回声会被跳过。
- 房间入口、等待室、牌桌、铃声日志、调试面板、无障碍标签和分享文本包含英文。
- 服务端错误提供稳定错误码及英文消息，客户端可用错误码本地化，而无需改变服务端协议。
- 玩家昵称、头像和语言设置均为设备本地偏好；游戏玩法仍由服务端裁定。

## 方案选择

### 翻牌声音

候选方案包括合成纸张噪声、玩家自行录音、使用授权的真实纸牌拟音。合成声难以达到“真的扑克牌”的目标；自录音需要额外采集。采用真实纸牌处理录音，剪出单张从牌堆抽出、翻转和轻落桌面的短段，避免整副牌洗牌声或音乐。当前候选是 Pixabay 的 [Placing playing card](https://pixabay.com/sound-effects/film-special-effects-placing-playing-card-522514/)；资源及许可来源随素材记录在仓库。

播放行为：

- 每次翻牌使用同一段音效，不随机改变音量或音色。
- 本机点击翻牌时立即播放；收到对手的翻牌事件时在本机播放一次。
- 服务端回送本机动作时不重复播放。
- 铃声、胜利、失败音效保持当前资源与行为。

### 语言支持

考虑了仅中文、内置双语字典和引入完整国际化框架三种方案。采用内置双语字典：两种语言范围有限，不额外引入依赖；中文作为初始默认语言，在设置中切换 `简体中文` / `English`。

语言由 Zustand 设置 store 管理并通过 AsyncStorage 在本机持久化。所有房间和游戏文案读取同一当前语言；房间服务端只发送稳定状态/错误码，客户端将已知错误码和申请状态映射成当前语言。未知错误显示当前语言的通用错误文案，不直接把英文服务端原文展示给中文玩家。另一位玩家的语言设置互不影响。

设置入口在房间入口、等待室和牌桌都可访问，并以轻量弹窗提供语言选择。切换后当前屏幕立即更新，不要求重启或离房。

## 文案范围

所有玩家可见的固定文案都需提供中英文，包括：

- 房间创建、开放房间、申请加入、房间码校验、取消申请及申请状态。
- 等待室的连接/准备状态、审批按钮、邀请分享与离房操作。
- 游戏轮次、断线提示、牌桌提示、翻牌/抢铃按钮、对局结束与再战。
- 双端抢铃活动日志、昵称/头像无障碍描述、调试面板。
- 网络错误码、服务器错误码和本地校验错误。

BellFive 品牌名、玩家自定义昵称、房间码、牌面水果图标和协议字段不翻译。玩家 ID 在简体中文界面显示为“玩家 1 / 玩家 2”，英文界面显示为“Player A / Player B”。

## 架构边界

- `src/i18n/` 保存 `zh-CN` 与 `en` 文案、键类型及纯翻译/插值函数。
- `src/store/settingsStore.ts` 单独持久化 `language`，不混进昵称/头像资料，也不上传服务器。
- 一个可复用的设置入口与语言弹窗嵌入房间入口、等待室和牌桌。
- 组件只通过翻译 API 读取界面文字；服务端错误根据 `code` 翻译。
- `assets/audio/card-flip.wav` 替换为真实录音的裁剪文件，继续由现有 `playCardFlipSound` API 播放。

## 验收标准

1. 清除本机设置或首次安装后显示简体中文。
2. 可从入口、等待室和牌桌打开设置并切换中英文；选择在重启后仍保留，两台设备可各自选择语言。
3. 房间/等待/游戏/日志/调试、可访问性、分享文案以及已知服务端错误都随语言切换；不出现意外英文（品牌名、昵称和房间码除外）。
4. 翻牌声来自真实纸牌处理录音，长度适合单张抽出翻面，不带洗牌长音；本机点击即时播放，对端事件只播放一次。
5. 铃声、胜负音效、房间协议、牌局规则和服务器裁定行为保持不变。
6. 对翻牌资源与语言存储/翻译建立回归测试；完整 Jest 套件、应用和服务器 TypeScript 检查通过。

## 不在本次范围

不加入自动语言检测、第三语言、在线玩家偏好同步、用户账户、语言专属音效设置、背景音乐、设置导航页或额外牌桌视觉改版。
