# 微信小游戏首页重新设计

目标：保留现有配色，重新组织首页，让第一次打开的玩家一眼找到开始游戏的入口。

设计：顶部小尺寸 BellFive 品牌与头像账号入口；紫色游戏主区以 3 + 2 草莓和铃铛解释规则，青柠色「开始单机」为唯一主操作；难度是独立选择，默认普通，选择不会直接开局。好友区域提供创建房间、同一行房间码和加入按钮；房间浏览集中到游戏大厅。语言切换在底部。房间实时更新不改变首页布局。

颜色复用 gameColors：canvas #F5F0FF、surface #FFFFFF、purple #7040C4、plum #34214F、lime #E3FB88、muted #796887。标题 24px，正文 12–14px，辅助 11px；使用系统字体以适应小游戏 Canvas，正文正常字重，标题与按钮加粗。

技术：首页布局尺寸与滚动高度由同一几何计算提供；顶部整体避开微信胶囊；主要按钮至少 56px，其他操作至少 44px。在线授权、建房锁定、取消、重试和房间码校验继续使用已有逻辑。错误在在线区域换行展示。未完成建房期间不能启动单机；授权失败后仍可单机。

验证：320×568、375×667、390×844 的首屏、胶囊、安全区、滚动点击、难度选择与单机开局；现有在线流程回归；小游戏类型检查和构建；渲染真实 Canvas 预览并检查。
