# BellFive 微信小游戏隐私与账号数据处理设计

## 目标

让 BellFive 微信小游戏在保留游客单机、微信登录和在线房间的情况下，做到数据用途清楚、个人信息处理可控、未满 14 周岁用户有监护人同意流程、用户能够查看和更正资料并注销账号。

本设计仅针对 Canvas 微信小游戏 minigame/，不改变 Expo/Web 客户端或 Taro 微信小程序 miniprogram/ 的行为。

## 当前项目背景

- minigame/src/entry.ts 在本地存储恢复后自动调用在线授权逻辑；没有有效会话时会取得微信登录 code 并尝试服务端登录，即使用户只想玩单机。
- minigame/src/platform/wechatLogin.ts 调用 wx.login。服务端兑换 code 后使用 AppID 和 OpenID 识别微信账号；当前不保存微信 session_key 或 UnionID。
- 服务端账号数据库保存用户名、密码盐和 scrypt 派生值、昵称、预设头像 ID、微信 OpenID、会话 token 的 SHA-256 摘要和到期时间。密码明文不写入数据库。会话有效期为 30 天；已过期的会话行目前没有清理任务。
- 小游戏本地存储保存账号资料和完整会话 token、游客昵称与头像选择、语言和音乐偏好。账号资料和游客资料使用不同的存储项。
- minigame/src/platform/wechatProfile.ts 只在用户点击微信原生用户信息按钮时读取昵称；随后只把昵称提交给账号服务。头像采用预设 Emoji，不上传微信头像或照片。
- 在线房间、房间码、玩家资料和对局动作由 server/src/roomManager.ts 保存在服务进程内存。没有账号战绩或房间历史数据库；房间关闭、超时或服务重启后，房间状态消失。
- 账号页支持查看用户名/微信绑定状态、编辑昵称和头像、退出登录；当前没有账号注销和隐私说明入口。
- 当前小游戏代码未发现手机号、定位、通讯录、相册上传、广告或分析 SDK 的采集流程。部署时反向代理、邮件服务和云主机自身日志仍需按实际供应商核实。
- 发布主体由个人开发者运营。个人开发者法定姓名、公开联系邮箱、隐私规则公开地址和生产服务供应商尚未提供，不能在正式隐私规则中编造。

## 方案选择

### 采用：完整的游戏内隐私说明和账号生命周期

保留游客单机、微信身份登录与在线玩法。启动过程不主动联网；玩家选择账号或联网功能时，先看到用途摘要和隐私规则，再按年龄路径继续。补齐微信隐私接口衔接、未成年人监护人邮箱确认、自助注销和用户资料处理机制。

该方案覆盖用户提出的隐私与账号数据处理，同时保持单机路径可用。监护人邮箱服务和部署服务信息是发布前需要配置的运行条件。

### 仅补文案并人工处理注销

可以较快补充隐私规则和微信后台声明，但账号数据删除仍依赖人工受理，处理体验和可验证性较差。本期不采用。

### 暂缓联网，只发布游客单机

能显著减少账号数据处理，但暂时取消微信账号与联机能力。本期不采用。

## 设计

### 1. 启动、隐私说明与年龄路径

- 删除小游戏启动时自动调用 authorizeOnline 的行为。打开游戏、单机开局和纯本地设置不调用 wx.login、账号 HTTP 接口或游戏 WebSocket。
- 用户主动登录、创建账号、绑定微信、使用在线房间或需要同步个人昵称时，显示“隐私与数据”说明。说明列出数据类别、用途、处理方式、服务端存储、用户权利和公开隐私规则入口，并记录所接受的规则版本。
- 在首次个性化资料或账号/联网操作前，用户选择“14 周岁及以上”或“未满 14 周岁”；不收集出生日期。14 周岁及以上用户确认已阅读规则后，继续微信登录或用户名登录。年龄选择只在本机流程中使用，不记录成年人的年龄；不同意时停留在游客单机路径。
- 未满 14 周岁用户仍可使用通用资料的游客单机；选择该年龄路径时清除此前保存在本机的自定义资料。在监护人确认前，不允许自定义昵称或头像、不创建联网账号、不调用用于账号识别的微信登录流程。
- 未满 14 周岁用户要自定义资料、创建账号或联网时，先展示监护人专用说明，再由监护人填写邮箱并打开一次性确认链接。服务端为此次申请生成随机请求标识，不关联孩子微信身份；确认页清晰列明孩子信息的用途与规则，并要求确认者声明其为法定监护人。流程核实邮箱访问权和监护人自我声明，不采集身份证件或出生日期。链接 24 小时失效；验证前不请求孩子的微信身份、不创建账号。监护人确认后，服务端删除待确认邮箱并签发一次性授权凭证；孩子随后完成账号登录或注册请求并提交该凭证，服务端将最少必要的未满 14 周岁标记、同意规则版本和时间关联到已验证账号。过期、已使用的请求和授权凭证均不可重放；账号注销时删除同意记录。
- 邮件投递通过服务端可配置的 SMTP 中继完成。接口层与具体邮件供应商解耦，正式部署时根据选用供应商填写名称、处理地区和保留期限。
- 在真实隐私相关微信接口前按微信小游戏官方接口流程查询隐私指引、触发授权及打开平台隐私规则。默认使用微信平台隐私弹窗，不注册自定义 wx.onNeedPrivacyAuthorization 监听器，避免自绘 Canvas 弹窗后未正确回报授权结果。
- 微信昵称仍是可选资料来源。用户可跳过，继续手动设置 BellFive 昵称；不请求相册、手机号或微信头像。

### 2. 数据清单、用途和保留期限

| 数据 | 来源 | 用途 | 存储位置和期限 |
| --- | --- | --- | --- |
| 微信临时登录 code | 用户主动进入微信账号/联网流程后调用 wx.login | 服务端向微信换取小游戏 OpenID | 仅随本次请求传输，不写入数据库或日志 |
| AppID、OpenID、内部用户 ID | 微信登录兑换与账号服务 | 识别、恢复和绑定 BellFive 账号 | 服务端账号数据库；账号有效期间保存，账号注销时删除 |
| 用户名、密码盐和 scrypt 派生值 | 用户主动注册、登录或设置凭据 | 账号登录和身份验证 | 服务端数据库；不保存明文密码；账号注销时删除 |
| 昵称和预设头像 ID | 用户输入、选择，或用户点击微信原生资料按钮后提供昵称 | 账号资料和在线对局展示 | 登录资料保存在服务端；游客资料保存在本机；按账号注销或清除本地资料处理 |
| 会话 token 和 token 摘要 | 登录成功后由服务端签发 | 维持登录状态、保护账号和房间操作 | token 保存在本机微信小游戏存储；服务端仅保存摘要并设置 30 天有效期；到期后清理 |
| 未满 14 周岁标记、监护人确认版本和时间 | 用户选择年龄路径、监护人确认 | 执行未成年人保护和证明同意范围 | 只为未满 14 周岁账号记录必要信息；不留存成年人的年龄选择；随账号注销删除 |
| 监护人邮箱 | 监护人发起邮箱确认 | 完成监护人确认 | 服务端待确认记录短期保存，最多 24 小时；成功或过期即删除。邮件供应商的处理依其实际规则披露 |
| 语言、音乐偏好 | 用户在游戏设置中选择 | 保存本机使用偏好 | 只保存在本机，不传给 BellFive 服务端 |
| 房间码、玩家资料、房间状态和游戏动作 | 已登录玩家在线游戏产生 | 运行好友房、公共房和对局 | 游戏服务进程内存中保存至房间结束/清理；不建立对局历史库；服务重启后清除 |

隐私规则须进一步列明：微信平台、BellFive 账号/房间服务、实际云主机与反向代理供应商，以及监护人邮件供应商。若托管服务记录 IP、请求时间或安全日志，须依据实际配置补充信息种类和期限。跨境存储/传输情况根据正式部署区域和供应商确认，不作未经核实的“不会跨境”承诺。

### 3. 个人信息入口、账号注销与清理

- 在首页和账号页提供可到达的“隐私与数据”入口；完整规则在游戏内可滚动阅读，并提供微信平台隐私保护指引入口。
- 账号页继续显示当前用户名、微信绑定状态、昵称和头像，并提供资料更正入口。个人信息副本、规则解释和其他权利申请可通过政策中公开的个人开发者邮箱提交。
- 增加“注销账号”入口，显示账号注销的影响：账号资料、凭据、微信绑定、会话和活跃房间数据删除；注销不能撤销。用户需重新验证：用户名账号输入当前密码，微信账号取得新的 wx.login code 并由服务端确认当前身份。
- 新增经认证的账号注销接口。服务端事务删除用户、密码凭据、微信 OpenID、隐私/监护人同意记录和全部会话；依外键级联删除关联数据。成功后立即撤销该用户的全部 WebSocket 连接、清除公共房间申请及内存中的座位/房间资料，并通知同房玩家房间已结束。
- 注销成功后，小游戏清除本机账号 token、账号资料缓存和游客自定义昵称，将本机资料恢复为默认值。语言和音乐偏好作为非账号偏好保留；用户可在单独的本机数据清理操作中重置。
- 定期删除已过期的会话记录。账号数据在账号保持有效期间保存；用户注销后从在线数据库删除。部署方必须明确备份覆盖周期，并在规则中说明备份中的残留数据最迟何时轮替清除。当前服务器部署信息不完整，因此正式保留期限属于发布阻断项。
- 如果注销请求遇到网络错误，客户端保留重试入口并说明服务端尚未确认删除；不能把单纯本机退出显示为账号已经注销。

### 4. 服务端与小游戏模块边界

- 新增小游戏隐私状态/说明屏和隐私流程协调器，集中执行规则版本、年龄路径、同意及用户退出逻辑。
- 扩展 minigame/src/platform/wxApi.ts 的微信隐私 API 类型与适配器；继续让纯游戏规则层不直接依赖 wx。
- 在账号客户端、状态仓库和账号页加入隐私同意、监护人邮箱确认及账号注销动作；登录与联网入口统一经过隐私协调器。
- 在服务端账号 HTTP API、服务、仓库和 SQLite schema 中加入同意记录、待确认监护人邮箱、验证 token 摘要与注销处理；邮件发送经可注入的 SMTP 发送器完成，凭据仅放服务端私密环境。
- 将账号删除与 WebSocket/RoomManager 生命周期协调，确保现有在线连接和内存房间不会在账号删除后继续保留该身份。
- 部署层定期清理过期会话和过期监护人请求。策略需可本地测试且在服务关闭时清理计时器。

### 5. 隐私规则和微信后台发布配置

交付一份简体中文的 BellFive 隐私规则，和小游戏内一致的简要数据清单。政策包含运营者姓名/身份、公开联系方式、处理目的与方式、全部信息类别、必要性、存储位置和期限、第三方受托方、未成年人专门条款、个人权利及申请路径、安全事件联系方法和生效日期/版本。

微信小游戏后台的用户隐私保护指引按实际启用接口和数据处理填写。用户信息仅声明为可选的昵称（只有运行时调用微信昵称按钮时）；登录 OpenID、账号凭据、监护人邮箱和服务器内的处理方式也需依后台要求如实说明。政策更新导致目的、方式或信息类别变化时，更新微信后台声明并重新取得适用的用户/监护人同意。

### 6. 错误和降级

- 用户拒绝隐私规则：不调用账号和在线接口；游客单机仍可开始。
- 微信隐私接口不可用或用户拒绝昵称授权：保留手动昵称输入；不阻止其他已同意且必要的账号功能。
- 监护人邮件发送失败或确认过期：不创建孩子账号、不调用孩子的微信登录；保留通用资料的游客单机和重新申请确认的入口。
- 账号注销服务不可用：显示删除未确认，允许重试；不要只清除客户端状态并宣称注销成功。
- SMTP 凭据、微信 AppSecret 和服务会话 token 不得输出到日志、小游戏包或公开配置。

### 7. 发布阻断项

上线前由发布者在本机或正式管理系统填写并核实以下信息，不向仓库提交私密凭据：

1. 微信小游戏主体登记使用的个人开发者准确姓名，以及公开联系邮箱/方式。
2. 可公开访问的隐私规则地址或微信可展示的完整隐私规则内容，生效日期和版本。
3. 账号服务、邮件发送、云主机/反向代理供应商名称，服务实际所在国家/地区及各供应商日志保留期。
4. 数据库和备份轮替期限；确认账号注销后的备份最晚删除时间。
5. SMTP 发件服务配置、发件地址和服务商处理规则；秘密凭据只配置在服务端环境。
6. 微信小游戏后台与真实 AppID 下的隐私保护指引、合法 request/socket 域名、正式 HTTPS/WSS、隐私 API 基础库支持情况。
7. 未满 14 周岁确认邮件展示的完整处理说明，邮件发送、24 小时失效、成功/过期删除邮箱和孩子账号创建顺序。
8. 核对发布包不含示例姓名、占位邮箱、测试账号、开发服务器地址或 AppSecret。

### 8. 验收范围

- 游客单机启动和对局不会请求微信 code、账号 API 或 WebSocket。
- 未同意用户仍可单机；账号和在线入口只有在相应隐私/年龄流程完成后继续。
- 未满 14 周岁流程在监护人确认前不会请求孩子微信身份、创建账号或保存自定义昵称；邮件确认只成功使用一次，超时/重复确认均安全失败。
- 未满 14 周岁游客单机使用通用资料；自定义昵称和头像只在监护人确认、账号创建后开放。
- 微信昵称仅在用户主动点击原生按钮后读取；手动昵称和预设头像路径可正常使用。
- 用户可查看和更正账号资料；密码数据库中没有明文；服务端会话过期后得到清理。
- 账号注销需重新验证；数据库中的用户、凭据、微信身份和会话被删除；账号的所有在线连接和活跃房间数据被清理；当前设备账号缓存和昵称恢复默认。
- 邮箱、微信密钥、密码、完整会话 token 和 OpenID 不进入应用诊断日志。
- 发布手册说明微信后台配置、个体开发者公开信息、云主机日志/备份期限和 SMTP 隐私规则；所有发布阻断项填充后再做微信真机验收。

## 资料依据

- 《中华人民共和国个人信息保护法》：第 6、14–19、28–31、44–50 条，涉及最小必要、告知、同意撤回、保存期限、未成年人和用户权利。
- 微信小游戏隐私接口：wx.getPrivacySetting、wx.requirePrivacyAuthorize、wx.openPrivacyContract 与小游戏隐私合规开发指南。
- 设计范围基于当前仓库 minigame/、server/src/auth/、server/src/roomManager.ts 的实现和现有小游戏操作手册。
