# 双手布局与背景音乐

本次更新采用底部双拇指操作：左手翻牌、右手抢铃。你自己的明牌始终在左侧，不受服务器 A/B 座位影响；头像区域改为昵称首字，避免水果头像干扰牌面判断。

背景配乐《Pocket Rally》为本项目原创的 38.4 秒循环，音乐开关独立于翻牌、抢铃和胜负音效。默认开启，在进入对局后首次有效操作或主动开启音乐时开始播放；离开对局、对局结束、断线暂停和切到后台时暂停。开关选择保存在本机。

## 只想试回旧版

先运行 `git status --short`，保存或提交后来产生的修改；然后：

```powershell
git switch --detach before-dual-thumb-2026-10-04
```

用项目原有的启动命令运行。试完回到新版所在分支：

```powershell
git switch main
```

## 正式撤回这次更新

可以直接对 Codex 说：“把双手布局和背景音乐回退到更新前。”会保留版本历史，通过反向提交撤回本次修改。

手动操作时，先确保工作区干净，再运行：

```powershell
git revert --no-commit before-dual-thumb-2026-10-04..dual-thumb-music-2026-10-04
git commit -m "revert: restore pre-dual-thumb game"
```

如果之后又改过相同文件，Git 可能提示冲突；此时先处理冲突，或执行 `git revert --abort` 取消这次撤回。不要使用 `git reset --hard`，以免丢失后续工作。
