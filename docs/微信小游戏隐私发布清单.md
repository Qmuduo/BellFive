# BellFive 微信小游戏隐私发布清单

> 下面标为「发布阻断」的事项未完成前，不要提交审核或公开发布。代码已提供自助隐私与账号流程，但代码不能代替实际主体、供应商、后台声明、生产部署和法定告知事实。

## 1. 主体与政策（发布阻断）

- [ ] 填写小游戏后台一致的个人开发者真实姓名/认证主体、权利请求渠道、安全联系渠道和政策生效日期。
- [ ] 将《隐私保护指引-微信小游戏》占位字段替换为真实信息，复核它与实际服务器、日志、备份和供应商一致。
- [ ] 发布可公开访问的正式隐私规则页面；确认线上入口可从游戏内隐私提示访问。
- [ ] 核实个人开发者运营、备案、游戏内容和未成年人服务要求；未成年人个人信息按敏感个人信息管理，并由监护人主动确认。
- [ ] 由发布者/法律顾问确认 14 至 17 周岁用户适用的告知、同意和服务要求；本实现只对不满 14 周岁设置监护人邮箱确认，不表示其他未成年人不受保护。
- [ ] 决定未满 14 周岁账号能否继续用于共用账号服务的 Web、Expo 和 Taro 客户端；确保监护人确认文字、这些客户端的政策和实际限制对跨客户端用途保持一致。

## 2. 微信开放平台/开发者工具（发布阻断）

- [ ] 使用实际注册小游戏 AppID；服务端 `BELLFIVE_WECHAT_MINI_APP_ID` 和 AppSecret 必须属于同一小游戏。
- [ ] 在微信后台声明 `wx.login`、网络请求、WebSocket、可选微信昵称及其真实目的、必要性和拒绝后的影响；不得声明代码未使用的手机号、头像、定位、相册或通讯录。
- [ ] 上传微信隐私保护指引，使 `wx.openPrivacyContract` 指向正式规则；在当前基础库和真机上确认 `wx.getPrivacySetting`、`wx.requirePrivacyAuthorize`、`wx.openPrivacyContract` 的行为。
- [ ] 在后台配置实际 HTTPS 请求合法域名和 WSS Socket 合法域名；证书有效，域名、AppID 与生产构建一致。不得把开发机地址作为生产域名。
- [ ] 仅对用户主动触发的账号、个性化资料、联机等操作发起网络请求；启动、设置页和游客离线单机不得自动登录或连接 WebSocket。

## 3. 服务部署、邮件和保留期限（发布阻断）

- [ ] 将 `BELLFIVE_PUBLIC_BASE_URL` 设置为公开 HTTPS 服务根地址；确认邮件链接可达且证书有效。
- [ ] 在服务器私密环境设置 SMTP host/port/TLS/user/password/from；确认供应商、处理地区、邮件日志、服务条款和隐私说明，并在政策中披露。
- [ ] 设置并轮换微信 AppSecret、SMTP 凭据和生产数据库访问凭据；仅放在服务器密钥管理中。禁止进入小游戏包、仓库、运行日志或构建日志。
- [ ] 确定并公布服务器国家/地区、SQLite 主库、访问日志、监控日志、邮件服务商日志、在线/离线备份的保存位置、访问权限和实际删除周期。
- [ ] 配置反向代理/WAF，使监护人确认链接的 token 查询参数、邮箱、表单正文、密码、微信 code 和账号令牌不进入访问日志/分析日志；确认错误追踪不采集请求正文。
- [ ] 为 SQLite 及备份设置访问控制、加密/密钥管理、恢复演练和到期删除；确认注销后备份中的数据何时彻底过期。
- [ ] 配置请求限速、告警、漏洞和数据事件响应流程；指定实际责任人及通知渠道。

## 4. 账号、隐私和儿童流程（真机发布阻断）

- [ ] 冷启动、游客单机、切换语言只使用本机状态；抓包确认没有 `wx.login`、账号 HTTP 或 WebSocket。
- [ ] 点击账号/资料/联机后先显示隐私和年龄流程；成人同意后按微信平台 `needAuthorization` 决定是否展示微信系统授权。
- [ ] 成人拒绝微信隐私授权、拒绝账号登录或返回后，仍可进入离线游客单机；拒绝时不得发起被拒绝的账号/网络动作。
- [ ] 未满 14 周岁路径不收集生日；监护人邮箱未确认前，只能用通用资料游客单机，不可修改昵称/头像、创建账号、登录或联网。
- [ ] 监护人邮件和确认页不加载第三方资源；只打开邮件链接不会授权；主动勾选提交后邮箱删除，授权码只显示一次、30 分钟过期且无法重放。
- [ ] 确认无效/过期邮件、邮箱发送失败、授权码无效/过期/重放时，不登录、不注册、不联网，且可返回游客单机。
- [ ] 账号页资料修改、自助注销可用；密码账号输入密码重新验证，微信专用账号调用新鲜 `wx.login` code 重新验证。
- [ ] 注销后检查主数据库账号、凭据、微信身份、同意记录、会话均删除；所有该账号 WebSocket 关闭；双方活动房间、申请和大厅条目立即清除；本机自定义资料清空且语言/音乐设置保留。
- [ ] 使用两台真机覆盖房主注销、申请者注销、游戏进行中注销、重复关闭事件、掉线后注销和网络失败重试；确保失败状态不显示“注销成功”。

## 5. 构建产物检查

- [ ] 生产构建只包含公开 HTTPS/WSS 地址，不含微信 AppSecret、SMTP 密码、监护确认 token/码、邮箱或生产账号。
- [ ] 用正式 AppID 和生产合法域名构建、导入微信开发者工具，检查 Console/Network，无未声明 API、失败授权后请求或敏感值日志。
- [ ] 将实际平台审核结论、隐私规则版本和部署配置归档；每次改动收集的数据、用途、服务商或保存周期变化时重新核对规则和后台声明。
